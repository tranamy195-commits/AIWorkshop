# Project Name
findfirst.js
# Project Description
It was a Node.js combination/recreation of the Linux commands "grep" and "head". It would look through the top "n" amount of lines looking for a "pattern" which was based on user input through a file that would also be provided via user input. It would then print the lines that contained this pattern.
